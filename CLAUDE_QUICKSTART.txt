⚡ QUICK SETUP (2 minutes)

1. Copy configuration template:
   $ cp .env.local.example .env.local

2. Get API key from https://console.anthropic.com/
   (Sign in → API keys → Create key)

3. Edit .env.local and add your key:
   ANTHROPIC_API_KEY=sk-ant-v1-YOUR_KEY_HERE

4. Run setup verification:
   $ python setup_claude.py
   
   Should show: ✅ Claude Haiku connection successful!

5. Run pipeline:
   $ python run_discovery_loop.py
   
   Will use Claude for hypothesis generation & experiment design!

📞 TROUBLESHOOTING

"ANTHROPIC_API_KEY not set"
  → Check .env.local exists and has your key
  → Run: python setup_claude.py

"401 Unauthorized"
  → API key format wrong or invalid
  → Get new key from console.anthropic.com

"anthropic library not installed"
  → Run: pip install anthropic

For more help:
  → See CLAUDE_SETUP_GUIDE.md section "Troubleshooting"
